# API Leírás és Végpont Spekifikáció
A rendszer egy RESTful HTTP API-t biztosít a parkolóhelyek és foglalások kezelésére. A be- és kimeneti adatok formátuma **JSON**.
---
## Interaktív Dokumentáció (Swagger & ReDoc)
Az alkalmazás futása közben az alábbi interaktív felületeken is tesztelhető az API:
- **Swagger UI:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)
- **OpenAPI Schema (JSON):** [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json)
